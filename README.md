# accurate-solar-system

## Goal
Create a representation of our solar system that is accurate in scale, timing, and arrangement that can be run in your browser with high fidelity.

## MVP Scope
An accurate arrangement of all eight planets orbiting around the sun with camera control.

## Future Plans
Add smooth camera movement, dynamic, detailed lighting, and a starfield background.

## Tech Stack
* **Languages:** C, CMake
* **Libraries:** Glad, GLFW, Libcurl, JQ
* **Tools:** Emscripten, NASA JPL Horizons API
